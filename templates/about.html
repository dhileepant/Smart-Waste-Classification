Model Architecture & System Specs

Deep dive into the Convolutional Neural Network (CNN) topology, OpenCV real-time image processing pipeline, and Flask deployment architecture.

🚀

Project Key Highlights & Accomplishments

✓
Automated Waste Classification System:

Engineered and trained a multi-block Convolutional Neural Network (CNN) in TensorFlow/Keras to categorize waste into recyclable and non-recyclable/hazardous types with high generalization accuracy.

✓
Real-Time OpenCV Image Processing Pipeline & Flask Deployment:

Constructed a high-throughput computer vision pipeline using OpenCV for frame ingestion, CLAHE contrast equalization, central ROI targeting, and dynamic HUD bounding boxes, deployed via Flask with live MJPEG streaming.

✓
Performance Optimization & Hyperparameter Tuning:

Optimized training convergence and model robustness through spatial Dropout ($0.25 - 0.50$), Batch Normalization, learning rate reduction on plateau (`ReduceLROnPlateau`), and data augmentations (rotation, zoom, shear, flips).

CNN Network Topology (3 Convolutional Stages)
44.5M Parameters

Stage 1: Low-Level Filters

  • Conv2D(32, 3x3) + ReLU
  • BatchNormalization()
  • Conv2D(32, 3x3) + ReLU
  • MaxPooling2D(2x2)
  • Dropout(0.25)

Stage 2: Mid-Level Textures

  • Conv2D(64, 3x3) + ReLU
  • BatchNormalization()
  • Conv2D(64, 3x3) + ReLU
  • MaxPooling2D(2x2)
  • Dropout(0.25)

Stage 3: High-Level Semantics

  • Conv2D(128, 3x3) + ReLU
  • BatchNormalization()
  • Conv2D(128, 3x3) + ReLU
  • MaxPooling2D(2x2)
  • Dropout(0.30)

Dense Classification Head & Softmax Engine

Flatten() → Dense(512, ReLU) → BatchNormalization() → Dropout(0.50) → Dense(2, Softmax).
Outputs categorical class probabilities for Recyclable vs. Hazardous waste.

⚙️ Hyperparameters & Training Setup

Input Tensor 224 × 224 × 3 (RGB)
Optimizer Adam (Initial LR: 0.001)
LR Scheduler ReduceLROnPlateau (factor: 0.3, patience: 3)
Loss Function Categorical Cross-Entropy
Batch Size 32 samples per step
Inference Speed ~11 - 14 ms per forward pass

📷 Real-Time OpenCV Pipeline

Color Standardization BGR → RGB conversion
Contrast Adjustment CLAHE (clipLimit=2.0, tileGrid=8x8)
Spatial Normalization Interpolated area resize & scaling [0, 1]
Target Segmentation Central Dynamic ROI Window
HUD Annotation Color-coded bounding box + FPS Telemetry
Stream Protocol MJPEG Multipart HTTP streaming
