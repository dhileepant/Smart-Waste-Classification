Model Architecture & System Design

Deep dive into the Convolutional Neural Network (CNN), OpenCV computer vision pipeline, and Flask deployment architecture.

🚀 Project Key Highlights

  • •
    Automated Waste Classification: Custom multi-block Convolutional Neural Network (CNN) categorizing waste into recyclable and hazardous/non-recyclable types with high accuracy.
  • •
    Real-Time OpenCV Pipeline & Flask Deployment: Low-latency image processing pipeline utilizing OpenCV for adaptive filtering, color conversion, ROI bounding box overlays, and MJPEG video streaming deployed via Flask.
  • •
    Performance Optimization & Hyperparameter Tuning: Extensive data augmentation (rotation, zooming, horizontal flipping, shear) and regularization (BatchNormalization, spatial Dropout, learning rate decay) delivering fast, robust predictions.

🧠 Convolutional Neural Network (CNN) Layers

Feature Extractor: Block 1

• Conv2D(32, 3x3) + ReLU
• BatchNormalization()
• Conv2D(32, 3x3) + ReLU
• MaxPooling2D(2x2)
• Dropout(0.25)

Mid-Level Patterns: Block 2

• Conv2D(64, 3x3) + ReLU
• BatchNormalization()
• Conv2D(64, 3x3) + ReLU
• MaxPooling2D(2x2)
• Dropout(0.25)

High-Level Semantics: Block 3

• Conv2D(128, 3x3) + ReLU
• BatchNormalization()
• Conv2D(128, 3x3) + ReLU
• MaxPooling2D(2x2)
• Dropout(0.30)

Classification Head

• Flatten() $\rightarrow$ Dense(512, ReLU) $\rightarrow$ BatchNormalization() $\rightarrow$ Dropout(0.50) $\rightarrow$ Dense(2, Softmax)
• Optimizer: Adam with learning rate reduction on plateau (decay factor 0.3)
• Loss Function: Categorical Cross-Entropy

📷 OpenCV Processing Pipeline

  • BGR to RGB Conversion: Standardizes color channels across camera hardware.
  • CLAHE Enhancement: Contrast Limited Adaptive Histogram Equalization for varied lighting conditions.
  • Spatial Resizing: Interpolation to $224 \times 224$ pixels matching CNN tensor dimensions.
  • Tensor Normalization: Pixel scaling from $[0, 255]$ integer range to $[0.0, 1.0]$ float32.
  • Live ROI HUD: Real-time bounding box rendering and category status banners.

🔄 Data Augmentation Strategy

  • Random Rotation: $\pm 25^\circ$ to handle orientation variance.
  • Width & Height Shift: $15\%$ translational jitter.
  • Shear Transformation: $15\%$ perspective distortion.
  • Zoom Range: $20\%$ scaling to simulate variable camera distances.
  • Horizontal Flipping: Simulates mirror symmetries of bottles, cans, and cartons.
